# Система планирования обслуживания бытовой техники

## Назначение

Проект предназначен для планирования и контроля обслуживания бытовой техники. Система должна помогать пользователю отслеживать запланированные работы и определять необходимость проведения обслуживания.

## Целевая аудитория

Целевой аудиторией являются владельцы бытовой техники, а также специалисты и небольшие сервисные организации, которые занимаются ее обслуживанием.

## Описание предметной области

Бытовая техника требует регулярного технического обслуживания. Для каждого устройства необходимо хранить информацию о самом устройстве, планируемых работах и датах их выполнения.

В рамках проекта будет разрабатываться система, которая позволит планировать обслуживание техники, создавать задачи и отслеживать их выполнение.

## Основные сущности

- Устройство
- Обслуживание
- Задача
- Дата

## Основные функции

- добавление информации об устройстве;
- планирование обслуживания;
- определение необходимости обслуживания;
- создание задач на обслуживание;
- просмотр запланированных работ;
- контроль сроков выполнения задач.

## План развития проекта

1. Добавить хранение нескольких устройств.
2. Реализовать сущности устройства, обслуживания и задачи.
3. Добавить возможность создания и изменения задач.
4. Реализовать хранение данных в базе данных.
5. Перенести проект на Django.
6. Добавить веб-интерфейс для работы с системой.
7. Реализовать фильтрацию и просмотр запланированных обслуживаний.
8. Добавить контроль выполнения и просроченных задач.
