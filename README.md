# Система планирования обслуживания бытовой техники

Консольное приложение для планирования и контроля обслуживания бытовой техники.

## Назначение

Проект предназначен для хранения и обработки информации о планируемом обслуживании бытовых устройств. Программа позволяет загружать задачи из JSON-файла, проверять сроки обслуживания и находить просроченные задачи.

## Целевая аудитория

Основными пользователями являются владельцы бытовой техники, а также специалисты и небольшие сервисные организации, занимающиеся ее обслуживанием.

## Предметная область

Бытовая техника требует регулярного технического обслуживания. Для устройств необходимо хранить информацию о планируемых работах и сроках их выполнения.

Основными сущностями проекта являются устройство, обслуживание, задача и дата.

## Возможности

* загрузка задач из JSON-файла;
* сохранение задач в JSON-файл;
* определение статуса обслуживания;
* расчет даты следующего обслуживания;
* поиск просроченных задач;
* сортировка задач по дате;
* обработка ошибок при работе с данными;
* автоматизированное тестирование функций.

## Структура проекта

* `src/maintenance_planning/main.py` – точка запуска программы;
* `src/maintenance_planning/service.py` – предметная логика;
* `src/maintenance_planning/repository.py` – работа с JSON-файлами;
* `src/maintenance_planning/data/tasks.json` – данные проекта;
* `tests/test_service.py` – автоматизированные тесты;
* `pyproject.toml` – настройки проекта и зависимости;
* `.pre-commit-config.yaml` – настройки проверок перед комитом;
* `Makefile` – основные команды проекта;
* `README.md` – описание проекта.

## Формат хранения данных

Данные хранятся в JSON-файле `src/maintenance_planning/data/tasks.json`.

Для каждой задачи сохраняются название устройства, дата обслуживания и признак выполнения задачи. Дата хранится в ISO-формате `YYYY-MM-DD`.

## Требования

* Python 3.11 или выше;
* Poetry;
* pytest;
* isort;
* Black;
* flake8;
* pre-commit.

## Установка

```bash
poetry install
```

## Запуск программы

```bash
poetry run python -m maintenance_planning.main
```

## Запуск тестов

```bash
poetry run pytest
```

## Форматирование кода

Для форматирования и сортировки импортов предусмотрена команда:

```bash
make format
```

Она запускает `isort` и `black` для каталогов `src` и `tests`.

## Проверка кода

Проверка с помощью `flake8`:

```bash
make lint
```

Полный запуск pre-commit-проверок:

```bash
make check
```

## План развития

В следующих практических работах проект планируется расширить за счет более детальной структуры данных, классов предметной области, миграции на реляционную БД и Django-интерфейса.
